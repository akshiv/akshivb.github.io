I finally got around to wiring up a blog on this site. It's built with Jekyll — GitHub Pages builds it natively, so publishing a post is just a pull request with a markdown file.

The plan is to write here about hardware, software, and whatever I'm tinkering with. This post is just a placeholder to prove the pipeline works end to end — feel free to edit or delete it before the real first post goes out.

A few things this setup gets for free:
- An RSS feed at `/feed.xml`
- A sitemap for search engines
- A one-command publish flow: drop a draft in `drafts/`, run `scripts/publish.sh`, review the PR

More soon.
